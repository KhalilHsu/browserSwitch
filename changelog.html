Release Notes

The journey of BrowserRouter — from the first commit to the latest features.

v1.3.0 v1.2.0 v1.1.0 v1.0.0
  1. v1.3.02026-09-23Latest

    Open Links From Anywhere

    • Services & clipboard: Send a selected link through the macOS Services menu, or open the link on your clipboard from the menu bar.
    • System language: Menus, onboarding, and settings follow your macOS language (English or Simplified Chinese).
    • Rule editor: Explicit New / Add / Save, Move Up and Move Down for priority, and a tester that previews the draft before it is saved.
    • Signed download: First Developer ID signed, Apple-notarized universal DMG; fixes restoring the previous default browser after automatic takeover.
  2. v1.2.02026-04-27

    Experience & Precision

    • Source App Routing: Route links based on the application that triggered them.
    • Browser Management: Reorder or hide browser profiles in the chooser.
    • Auto-Restore: Automatically switch back to your system browser on quit.
    • UI Polish: Refined onboarding and settings window layout.
  3. v1.1.02026-04-22

    Architecture & Stability

    • Modularized code structure for better long-term maintainability.
    • Migrated testing suite to XCTest for robust quality assurance.
    • Improved shortcut detection reliability across different keyboard layouts.
  4. v1.0.02026-04-17

    The Beginning

    • Initial release of the native macOS link router.
    • Core browser and profile discovery for Chrome, Firefox, Edge, and more.
    • Keyboard-triggered chooser for manual link routing.
