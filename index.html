Developer ID signed and notarized by Apple. Drag it into Applications, then set BrowserRouter as your default browser.

Or build from source

BrowserRouter is currently in beta. You can install it directly from the source using our installation script.

git clone https://github.com/KhalilHsu/browserSwitch.git && \
cd browserSwitch && \
chmod +x scripts/install.sh && \
./scripts/install.sh

Requires local Swift build tools and installs the app into /Applications.

  • Local configurationRules and browser preferences stay in Application Support on your Mac.
  • No telemetryBrowserRouter does not upload URLs or collect browsing history.
